# Pulley Casting & Machining – CAD Model

## Project Overview

Designed and modeled a **Pulley** using **CATIA V5**, focusing on casting geometry, machining considerations, and accurate dimensional features.

## Features

* Created a detailed 3D pulley model
* Developed casting geometry with machining considerations
* Applied accurate dimensions and geometric constraints
* Created bore and groove features
* Focused on manufacturable and functional geometry

## Software Used

* **CATIA V5**
* 3D CAD Modeling
* Parametric Modeling

## Skills Demonstrated

* Casting Component Design
* Machining Considerations
* Solid Modeling
* Mechanical Component Design
* Precision CAD Modeling
